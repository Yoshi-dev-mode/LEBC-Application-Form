## ✦ About

The **LEBC Music Ministry Registration** website introduces visitors to music training opportunities and provides direct access to the appropriate application forms.

Built with plain HTML, CSS, and JavaScript, the project keeps the experience lightweight, responsive, and easy to maintain.

## ✦ What it offers

| Feature | Description |
| --- | --- |
| **Two application paths** | Separate links for music training and joining the ministry |
| **Responsive layout** | Designed to adapt to desktop and mobile screens |
| **Guided application access** | A checkbox controls access to the ministry application link |
| **Accessible interactions** | Visible keyboard focus and reduced-motion support |
| **Form handling** | Google Forms collects submissions; the site has no application database |

> **Eligibility notice**  
> The baptism checkbox is a front-end interaction, not identity or eligibility verification. Eligibility should be confirmed during the application review process.

## ✦ Run locally

No package installation or build step is required.

```bash
git clone https://github.com/Yoshi-dev-mode/LEBC-Application-Form.git
cd LEBC-Application-Form
```

Open `index.html` in your browser, or use **Live Server** in Visual Studio Code to preview the site locally.

## ✦ Before each registration period

- [ ] Confirm both Google Forms are accepting responses.
- [ ] Check the form URLs in `index.html`.
- [ ] Test the training and ministry application paths.
- [ ] Review the layout on mobile and desktop.
- [ ] Confirm the logo loads correctly.

## ✦ Deployment

This is a static website and can be hosted with **GitHub Pages** or another static web host.

For GitHub Pages, open **Settings → Pages**, select the deployment source and branch, then save. Add the published URL here when deployment is configured.
